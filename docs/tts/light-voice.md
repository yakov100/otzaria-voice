# "חיים קל": קול מזוקק, קטן ומהיר

*מסמך עבודה, מתעדכן תוך כדי. התכנית המלאה אושרה ב-16.10.2026.*

## הרעיון
הקול המוקלט "חיים" רץ על Chatterbox Multilingual: 900MB להורדה, והכנת MP3 בקצב של אורך ההקראה.
במקום לשלוח את המודל הכבד למשתמשים, הוא משמש אצלנו בלבד: מקריא עשרות שעות של טקסט תורני,
ועל ההקלטות האלה מאמנים מודל VITS קטן (Piper, ~63MB, פי 30–50 מזמן אמת על CPU) שמדבר באותו
קול (זיקוק, distillation). המודל הכבד נשאר כאופציית "איכות מלאה".

## עובדות שנקבעו
- **הגייה:** הקול המקורי של חיים הוקלט בהגייה רגילה (נבדק באוזן ב-16.10). לכן מההקלטות
  האמיתיות (`C:\Users\fried\otzaria-stt\rec`) נכנסות רק 149 ההקלטות המתויגות `regular` (24 דקות);
  390 הישיבתיות לא.
- **ייצוג הטקסט לאימון:** טקסט מנוקד + סימני Phonikud (֫ U+05AB הטעמה, ֽ U+05BD שווא נע),
  `--data.phoneme_type text` ב-Piper. בלי espeak ובלי IPA, כך שבזמן ריצה צריך רק ניקוד.
- **המנקד בזמן ריצה:** עד שיהיה מנקד זעיר, חבילת הקול הקל כוללת את `nakdan.onnx` (308MB) למי שאין
  לו את החבילה הכבדה (~370MB), או רק את הקול (~65MB) למי שיש.
- **בקרת איכות:** מזהה הדיבור של השירות (GigaAM-He, CTC) עם השוואה "לפי צליל" (ת/ט, כ/ק/ח,
  ש/ס, אותיות שקטות, בלי ו/י). על ההקלטות האמיתיות: CER חציוני 0.0, אחוזון 90 = 0.05; סף
  הפסילה 0.15. בנוסף: 6–18 אותיות לשנייה, בלי שקט פנימי > 1.5 ש', קיצוץ < 0.1%.
- **אימון:** Colab Pro. ניסוי מבסיס `he_IL-saspeech` (לא-מסחרי, לניסוי בלבד); אימון סופי מבסיס חופשי
  (`en_US-lessac`).
- **הסכמה:** חיים (המשתמש) מסכים.

## הצינור והכלים
`tools/tts/distill/README.md` מתאר את ההרצה צעד-צעד. בקצרה: `select_text.py` (17,267 משפטים,
300 אלף מילים, 45% גמרא / 20% משנה / 15% תנ"ך וסידור / 10% רש"י / 10% הלכה) →
`--vocalize --marks` → `generate.py` (shards, המשך אוטומטי, עדיפות נמוכה) + `import_recordings.py`
→ `qc.py` → `make_dataset_zip.py` → `train_colab.ipynb` → `chaim-light.onnx`.
