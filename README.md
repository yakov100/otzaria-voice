# הקלדה בדיבור לאוצריא

מדברים, והטקסט נכתב תוך כדי דיבור. בלחיצה אחת מחפשים אותו בספרייה של [אוצריא](https://github.com/Otzaria/otzaria).
זיהוי הדיבור נעשה **במחשב שלכם בלבד**, בלי אינטרנט.

## משני חלקים

1. **התוסף "חיפוש בדיבור"** (קובץ `.otzplugin`). זה החלון שרואים בתוך אוצריא.
2. **שירות הדיבור.** תוכנה קטנה שרצה ברקע במחשב. היא מקשיבה למיקרופון ומזהה את הדיבור.

למה צריך שני חלקים? לתוספים של אוצריא אין גישה למיקרופון.
לכן השירות מקליט ומזהה, והתוסף רק מבקש ממנו את הטקסט.
הם מדברים ביניהם דרך כתובת מקומית במחשב (`http://127.0.0.1:47811`), שאינה יוצאת אל הרשת.

**חבילת הקול** היא המודל שמזהה את הדיבור (כ-330 מגה-בייט). השירות צריך אותה כדי לעבוד.
לכל מערכת יש שני מתקינים:

- **`with-models`**: כולל את חבילת הקול. עובד מיד, גם בלי אינטרנט.
- **`without-models`**: קטן. השירות יוריד את חבילת הקול בפעם הראשונה שתשתמשו בו.

## התקנה

את כל הקבצים מורידים מ[דף הגרסאות](https://github.com/yakov100/otzaria-voice/releases).

### התוסף

באוצריא: **כלים ← תוספים ← התקנת תוסף חדש**, ובוחרים את קובץ ה-`.otzplugin`.
אפשר גם להתקין אותו מחנות התוספים של אוצריא.

### שירות הדיבור ב-Windows

1. מורידים את `otzaria-voice-windows-x64-with-models-….exe` (או `without-models`).
2. מפעילים אותו. לא צריך הרשאות מנהל. ההתקנה היא למשתמש הנוכחי בלבד.
3. השירות מתחיל לפעול, ומעכשיו יעלה מעצמו בכל כניסה למחשב.

ב-Windows השירות משתמש במנוע ONNX Runtime שמגיע עם אוצריא, ולכן אוצריא צריכה להיות מותקנת.
Windows עלולה להציג אזהרה ("Windows הגן על המחשב"), כי המתקין אינו חתום. לוחצים "מידע נוסף" ← "הפעל בכל זאת".

**הסרה:** הגדרות ← אפליקציות ← אפליקציות מותקנות ← "שירות הדיבור של אוצריא".
חבילת הקול נשארת בתיקייה `%APPDATA%\otzaria\stt\pack`. אפשר למחוק אותה ידנית.

### שירות הדיבור ב-Linux

**אובונטו, דביאן ודומיהן:** מורידים את קובץ ה-`.deb` המתאים (`x64` למחשב רגיל, `arm64` למעבד ARM), ומתקינים:

```
sudo apt install ./otzaria-voice-linux-x64-with-models-….deb
```

השירות יעלה מעצמו בכניסה הבאה למחשב. להסרה: `sudo apt remove otzaria-voice`.

**כל הפצה אחרת:** מורידים את קובץ ה-`.tar.gz`, פותחים אותו, ומריצים:

```
./otzaria-voice/install.sh
```

ההתקנה היא למשתמש הנוכחי בלבד, בלי הרשאות מנהל, והשירות מתחיל לפעול מיד. להסרה: `./otzaria-voice/install.sh --uninstall`.

### שירות הדיבור ב-macOS

מתאים למחשבי מק עם מעבד Apple (M1 ואילך).

1. מורידים את קובץ ה-`.pkg`.
2. המתקין אינו חתום אצל Apple. לכן בפעם הראשונה: **קליק ימני על הקובץ ← "פתיחה" ← "פתיחה"**.
   אם macOS עדיין חוסמת: הגדרות המערכת ← פרטיות ואבטחה ← "פתיחה בכל זאת".
3. בפעם הראשונה שתכתיבו, macOS תשאל אם לאשר לשירות להשתמש במיקרופון. מאשרים.

**הסרה:** בטרמינל:

```
sudo "/Library/Application Support/OtzariaVoice/uninstall.sh"
```

### שירות הדיבור באנדרואיד

מורידים את קובץ ה-`.apk` ומתקינים אותו (צריך לאשר "התקנה ממקורות לא ידועים").
פותחים את האפליקציה "שירות הדיבור של אוצריא" פעם אחת ומאשרים לה את המיקרופון.

אחרי הפעלה מחדש של הטלפון, אנדרואיד לא מרשה לשירות להשתמש במיקרופון עד שפותחים את האפליקציה שוב.
זו מגבלה של אנדרואיד, והתוסף מסביר אותה כשהיא קורית.

## פרטיות

- הקול **לא יוצא מהמחשב**. ההקלטה והזיהוי נעשים במחשב שלכם.
- השירות מאזין רק לכתובת המקומית `127.0.0.1`, ולכן מחשבים אחרים ברשת אינם יכולים לפנות אליו.
- המיקרופון פועל רק בזמן הכתבה.
- הגישה היחידה לאינטרנט היא הורדת חבילת הקול מדף הגרסאות של הפרויקט, ורק אם לא התקנתם אותה עם השירות.

## למפתחים

- `service/`: קוד שירות הדיבור (C++, נבנה עם CMake), ו-`service/android/` לאפליקציית האנדרואיד. פרטים בקובץ `docs/platforms.md`.
- `plugin/`: מקורות התוסף. הפקודה `python plugin/build.py` יוצרת ממנו שתי חבילות:
  - `released`: לגרסת אוצריא הנוכחית. זו החבילה שמתפרסמת בחנות ובדף הגרסאות.
  - `next`: לגרסת אוצריא הבאה (כפתור מיקרופון בתוך שדות החיפוש). היא נבנית רק כקובץ לבדיקה, ולא מתפרסמת.
- `installer/`: סקריפטים לבניית המתקינים לכל מערכת.
- `.github/workflows/build.yml`: בכל דחיפה בונה את השירות לכל המערכות, את המתקינים ואת התוסף.
  הוא מתקין כל מתקין על מחשב הבדיקה (באנדרואיד: באמולטור), מריץ דרכו הכתבה, ומעלה את כל הקבצים כ-Artifacts של הריצה.
  כשמעלים את מספר הגרסה ב-`plugin/manifest.base.json` ודוחפים ל-`main`, נוצרת גרסה חדשה בדף הגרסאות עם כל הקבצים, והתוסף מתפרסם בחנות של אוצריא.

### פרסום לחנות אוצריא

הפרסום לחנות נעשה אוטומטית, אבל רק אחרי שמגדירים במאגר (**Settings ← Secrets and variables ← Actions**):

- סוד `OTZARIA_USER`: שם המשתמש או האימייל בחנות.
- סוד `OTZARIA_PASSWORD`: הסיסמה לחנות.

בלי הסודות האלה הפרסום מדולג, וכל השאר ממשיך לעבוד.
**בפרסום הראשון** החנות דורשת עוד שני דברים:

- לפחות צילום מסך אחד של התוסף: שמים קבצי PNG בתיקייה `screenshots/` בשורש המאגר.
- הסכמה לקבל דיווחי באגים מהמשתמשים לאימייל: משתנה (Variable, לא סוד) בשם `OTZARIA_REPORTS_CONSENT` עם הערך `true`.

### חבילת הקול
