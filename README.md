# דיבור באוצריא: הקלדה בדיבור והקראה קולית

שני תוספים ל[אוצריא](https://github.com/Otzaria/otzaria), ושירות דיבור אחד שמשרת את שניהם:

- **חיפוש בדיבור**: מדברים, והטקסט נכתב תוך כדי דיבור. בלחיצה אחת מחפשים אותו בספרייה.
- **הקראה קולית**: הספר הפתוח מוקרא בקול והמילה הנקראת מודגשת, ואפשר לשמור פרק או קטע מסומן
  כקובץ MP3, בקול של Windows ("אסף") או בקול מוקלט ("חיים").

הכל נעשה **במחשב שלכם בלבד**, בלי אינטרנט (חוץ מהורדה חד-פעמית של חבילות הקול).

## משלושה חלקים

1. **התוספים** (קובצי `.otzplugin`). זה מה שרואים בתוך אוצריא. אפשר להתקין אחד מהם או את שניהם.
2. **שירות הדיבור.** תוכנה קטנה שרצה ברקע במחשב, מותקנת פעם אחת. היא מקשיבה למיקרופון ומזהה
   את הדיבור, ומקריאה טקסט לקובץ MP3.
3. **חבילות הקול**, שהשירות מוריד לפי הצורך: חבילת ההקלדה בדיבור (כ-330 מגה-בייט) וחבילת
   הקול המוקלט להקראה (כ-900 מגה-בייט). כל חבילה יורדת פעם אחת, ושני התוספים משתמשים בה.

למה צריך שירות נפרד? לתוספים של אוצריא אין גישה למיקרופון ולא לשמירת קבצים כבדים.
לכן השירות מקליט, מזהה ומקריא, והתוסף רק מבקש ממנו את התוצאה.
הם מדברים ביניהם דרך כתובת מקומית במחשב (`http://127.0.0.1:47811`), שאינה יוצאת אל הרשת.

ההקראה הרגילה בתוך אוצריא (כפתור הרמקול) אינה צריכה את השירות כלל: היא משתמשת בקול העברי של
Windows. השירות נחוץ רק לשמירה כ-MP3 ולקול המוקלט.

**חבילת ההקלדה בדיבור** היא המודל שמזהה את הדיבור (כ-330 מגה-בייט). לכל מערכת יש שני מתקינים:

- **`with-models`**: כולל את חבילת הקול. עובד מיד, גם בלי אינטרנט.
- **`without-models`**: קטן. השירות יוריד את חבילת הקול בפעם הראשונה שתשתמשו בו.

## התקנה

את כל הקבצים מורידים מ[דף הגרסאות](https://github.com/yakov100/otzaria-voice/releases).

### התוספים

הדרך הפשוטה: **חנות התוספים של אוצריא** ← "חיפוש בדיבור" או "הקראה קולית" ← התקנה.
אפשר גם מקובץ: **כלים ← תוספים ← התקנת תוסף חדש**, ובוחרים את קובץ ה-`.otzplugin` מדף הגרסאות.

כשהתוסף צריך את שירות הדיבור והוא אינו מותקן, התוסף מציע להוריד את תוכנת ההתקנה.
מפעילים אותה פעם אחת, וזהו.

### הקראה קולית: מה קורה בפעם הראשונה

- **הקראה בקול "אסף"** עובדת מיד, בתנאי שבמחשב מותקן דיבור עברי:
  הגדרות Windows ← זמן ושפה ← דיבור ← הוספת קולות ← עברית.
- **שמירה כ-MP3** דורשת את שירות הדיבור. בפעם הראשונה התוסף מציע להוריד אותו.
- **הקול המוקלט "חיים"**: בפעם הראשונה שבוחרים בו, התוסף מציע להוריד את חבילת הקול
  (כ-900 מגה-בייט, הורדה חד-פעמית). ההכנה של קובץ בקול הזה איטית: בערך כאורך ההקראה (במחשב עם 10 ליבות).
  בנוסף יורד בשקט מילון ניקוד קטן (כ-1.2 מגה-בייט) שמשפר את הניקוד של ארמית ולשון חז"ל.
- **הסרה**: את התוסף מסירים מפאנל התוספים של אוצריא. את הקול המוקלט אפשר למחוק מהתפריט
  שליד כפתור הרמקול ("הסר את הקול המוקלט מהמחשב"). את שירות הדיבור, יחד עם כל חבילות הקול,
  מסירים דרך הגדרות Windows ← אפליקציות ← Otzaria Voice ← הסרה.
- שמירה כ-MP3 זמינה כרגע ב-Windows בלבד.

### שירות הדיבור ב-Windows

1. מורידים את `otzaria-voice-windows-x64-with-models-….exe` (או `without-models`).
2. מפעילים אותו. לא צריך הרשאות מנהל. ההתקנה היא למשתמש הנוכחי בלבד.
3. השירות מתחיל לפעול, ומעכשיו יעלה מעצמו בכל כניסה למחשב.

ב-Windows השירות משתמש במנוע ONNX Runtime שמגיע עם אוצריא, ולכן אוצריא צריכה להיות מותקנת.
Windows עלולה להציג אזהרה ("Windows הגן על המחשב"), כי המתקין אינו חתום. לוחצים "מידע נוסף" ← "הפעל בכל זאת".

**הסרה:** הגדרות ← אפליקציות ← אפליקציות מותקנות ← "שירות הדיבור של אוצריא".
חבילת הקול נשארת בתיקייה `%APPDATA%\otzaria\stt\pack`. אפשר למחוק אותה ידנית.

### שירות הדיבור ב-Linux

**אובונטו, דביאן ודומיהן:** מורידים את קובץ ה-`.deb` המתאים (`x64` למחשב רגיל, `arm64` למעבד ARM), ומתקינים:

```
sudo apt install ./otzaria-voice-linux-x64-with-models-….deb
```

השירות יעלה מעצמו בכניסה הבאה למחשב. להסרה: `sudo apt remove otzaria-voice`.

**כל הפצה אחרת:** מורידים את קובץ ה-`.tar.gz`, פותחים אותו, ומריצים:

```
./otzaria-voice/install.sh
```

ההתקנה היא למשתמש הנוכחי בלבד, בלי הרשאות מנהל, והשירות מתחיל לפעול מיד. להסרה: `./otzaria-voice/install.sh --uninstall`.

### שירות הדיבור ב-macOS

מתאים למחשבי מק עם מעבד Apple (M1 ואילך).

1. מורידים את קובץ ה-`.pkg`.
2. המתקין אינו חתום אצל Apple. לכן בפעם הראשונה: **קליק ימני על הקובץ ← "פתיחה" ← "פתיחה"**.
   אם macOS עדיין חוסמת: הגדרות המערכת ← פרטיות ואבטחה ← "פתיחה בכל זאת".
3. בפעם הראשונה שתכתיבו, macOS תשאל אם לאשר לשירות להשתמש במיקרופון. מאשרים.

**הסרה:** בטרמינל:

```
sudo "/Library/Application Support/OtzariaVoice/uninstall.sh"
```

### שירות הדיבור באנדרואיד

מורידים את קובץ ה-`.apk` ומתקינים אותו (צריך לאשר "התקנה ממקורות לא ידועים").
פותחים את האפליקציה "שירות הדיבור של אוצריא" פעם אחת ומאשרים לה את המיקרופון.

**עדכון:** מתקינים את קובץ ה-`.apk` החדש על הקיים, בלי להסיר אותו, וחבילת הקול לא יורדת שוב.
מי שהתקין גרסה 2.5.1 או ישנה ממנה צריך להסיר אותה פעם אחת לפני ההתקנה. ההסרה מוחקת גם את חבילת הקול, והיא תרד שוב.

אחרי הפעלה מחדש של הטלפון, אנדרואיד לא מרשה לשירות להשתמש במיקרופון עד שפותחים את האפליקציה שוב.
זו מגבלה של אנדרואיד, והתוסף מסביר אותה כשהיא קורית.

## פרטיות

- הקול **לא יוצא מהמחשב**. ההקלטה והזיהוי נעשים במחשב שלכם.
- השירות מאזין רק לכתובת המקומית `127.0.0.1`, ולכן מחשבים אחרים ברשת אינם יכולים לפנות אליו.
- המיקרופון פועל רק בזמן הכתבה.
- הגישה היחידה לאינטרנט היא הורדת חבילות הקול מדף הגרסאות של הפרויקט, בפעם הראשונה שצריך אותן.
- בהקראה בקול המוקלט הטקסט אינו נשלח לשום מקום: הניקוד האוטומטי וההקראה נעשים במחשב.

## למפתחים

- `service/`: קוד שירות הדיבור (C++, נבנה עם CMake). `service/src/common/` משותף להכתבה ולהקראה, `service/src/dictation/` להכתבה בלבד ו-`service/src/tts/` להקראה בלבד. כלי העזר ב-`tools/dictation/` וב-`tools/tts/`, והתיעוד ב-`docs/dictation/`, `docs/tts/` ו-`docs/shared/`, ו-`service/android/` לאפליקציית האנדרואיד. פרטים בקובץ `docs/shared/platforms.md`.
- `plugins/read-aloud/`: התוסף "הקראה קולית", כפי שהוא נארז (`otzaria pack-plugin plugins/read-aloud`).
- `plugins/dictation/`: מקורות התוסף "חיפוש בדיבור". הפקודה `python plugins/dictation/build.py` יוצרת ממנו שתי חבילות:
  - `released`: זו החבילה שמתפרסמת בחנות ובדף הגרסאות. מגרסה 2.3.0 היא דורשת אוצריא 0.9.98.1 ומעלה, וכוללת כפתור מיקרופון בתוך שדות החיפוש. באוצריא 0.9.98 נשארים עם 2.2.3.
  - `next`: מקום לחבילה שדורשת אוצריא חדשה יותר מזו שבחנות. היא נבנית רק כקובץ לבדיקה, ולא מתפרסמת. כרגע היא זהה ל-`released`.
- `installer/`: סקריפטים לבניית המתקינים לכל מערכת.
- `.github/workflows/`: שלושה תהליכי בנייה נפרדים, וכל אחד רץ רק כשמשנים את החלק שלו:
  - `service.yml`: השירות לכל המערכות והמתקינים (רץ כשמשתנה `service/` או `installer/`). הוא מתקין כל מתקין על מחשב הבדיקה (באנדרואיד: באמולטור), מריץ דרכו הכתבה, ומעלה את הקבצים. כשמעלים את `kVersion` ב-`service/src/common/service.cpp` ודוחפים ל-`main`, נוצרת גרסה `service-vX.Y.Z` בדף הגרסאות. זו הגרסה המסומנת "latest", כי התוספים מורידים ממנה את המתקין.
  - `dictation.yml`: תוסף "חיפוש בדיבור". כשמעלים את `version` ב-`plugins/dictation/manifest.base.json` ודוחפים ל-`main`, נוצרת גרסה `dictation-vX.Y.Z`.
  - `read-aloud.yml`: תוסף "הקראה קולית". כשמעלים את `version` ב-`plugins/read-aloud/manifest.json` ודוחפים ל-`main`, נוצרת גרסה `read-aloud-vX.Y.Z`.
  גרסאות התוספים אינן מסומנות "latest", והתוספים אינם מתפרסמים בחנות בדחיפה רגילה (ראו "פרסום לחנות אוצריא").

### פרסום לחנות אוצריא

הפרסום לחנות נעשה רק במכוון: בהפעלה ידנית של הבנייה בענף `main` (**Actions ← תוסף חיפוש בדיבור (הכתבה) ← Run workflow**), או בכל דחיפה ל-`main` כשהמשתנה `PUBLISH_DICTATION` במאגר הוא `true`. דחיפה רגילה ל-`main` בונה ויוצרת גרסה בגיטהאב, ומשאירה את החנות כמות שהיא. כדי שהפרסום יעבוד צריך להגדיר במאגר (**Settings ← Secrets and variables ← Actions**):

- סוד `OTZARIA_USER`: שם המשתמש או האימייל בחנות.
- סוד `OTZARIA_PASSWORD`: הסיסמה לחנות.

בלי הסודות האלה הפרסום מדולג, וכל השאר ממשיך לעבוד.
**בפרסום הראשון** החנות דורשת עוד שני דברים:

- לפחות צילום מסך אחד של התוסף: שמים קבצי PNG בתיקייה `screenshots/` בשורש המאגר.
- הסכמה לקבל דיווחי באגים מהמשתמשים לאימייל: משתנה (Variable, לא סוד) בשם `OTZARIA_REPORTS_CONSENT` עם הערך `true`.

### חבילות הקול

חבילות הקול גדולות מדי בשביל git. הן שמורות כקבצים בגרסאות ייעודיות, ומשם השירות (ותהליך
הבנייה) מורידים אותן. טביעת ה-SHA-256 של כל חבילה נבדקת בכל הורדה.

- **הקלדה בדיבור**: [`voice-pack-v4`](https://github.com/yakov100/otzaria-voice/releases/tag/voice-pack-v4),
  `6ae8112931042ee86889336418a111de90f73e3d5bdac5ce361e24955358f048`.
- **הקראה בקול מוקלט**: [`voice-model-v1`](https://github.com/yakov100/otzaria-voice/releases/tag/voice-model-v1),
  `3a757b8888699a48661bb1b43096bf5cf00035b6b23d8e3fdf4152d5b4c2af06`. נבנית מתיקיית מודלים
  עובדת בפקודה `python tools/tts/make_voice_model.py <תיקייה> <out.zip>`; קובץ קול (`.otzvoice`)
  נוצר מהקלטה בעזרת `tools/tts/make_voice_from_wav.py` (ראו להלן). פרטי המודלים ב-`docs/tts/tts-research.md`.

### הוספת קול מוקלט משלכם

ההקראה בקול מוקלט משכפלת קול מתוך הקלטה קצרה. החבילה מגיעה עם קול אחד ("חיים"), ואפשר להוסיף עוד:

1. מקליטים דובר אחד, 10 עד 30 שניות של דיבור נקי (בלי מוזיקה ורעש), בכל פורמט נפוץ
   (WAV, FLAC, OGG, בכל קצב דגימה). רק 10 השניות הראשונות של הדיבור נכנסות לקול, זו מגבלת המודל,
   ולכן כדאי שיהיו רצופות וברורות.
2. מריצים פעם אחת `pip install numpy onnxruntime soundfile huggingface_hub`, ואז:

   ```bash
   python tools/tts/make_voice_from_wav.py recording.wav moshe.otzvoice
   ```

   בהרצה הראשונה הסקריפט מוריד את מקודד הדיבור של Chatterbox Multilingual (כ-590MB) לתיקיית
   `%LOCALAPPDATA%\OtzariaVoice\speech_encoder` (ב-Linux/macOS: `~/.cache/otzaria-voice/speech_encoder`;
   `--speech-encoder <תיקייה>` או משתנה הסביבה `OTZARIA_SPEECH_ENCODER` בוחרים מקום אחר).
   המקודד מריץ על ההקלטה את ארבעת המערכים שהמקריא צריך (`cond_emb`, `prompt_token`,
   `ref_x_vector`, `prompt_feat`) וכותב אותם לקובץ `.otzvoice` של כ-300KB. `--start <שניות>` מדלג על
   תחילת ההקלטה, ו-`--no-trim` משאיר את השקט בתחילתה ובסופה.
3. מעתיקים את הקובץ ל-`%APPDATA%\otzaria\tts\voices\<מזהה>.otzvoice` (ב-Linux/macOS: תיקיית הנתונים
   של אוצריא, `tts/voices`). המזהה הוא שם הקובץ בלי הסיומת, באותיות לטיניות. השירות מוצא את הקובץ
   בהפעלה הבאה ומחזיר את המזהה ברשימת `voices` של `GET /status`.
4. בתפריט ההקראה באוצריא מופיע פריט "קול לשמירה: <מזהה> (מוקלט)" לכל קול מותקן: התוסף קורא את רשימת
   `voices` מהשירות כשהוא עולה (בלחיצה הראשונה על אחד מפריטי התפריט, או בהפעלת אוצריא כשהתוסף מורשה
   לרוץ ברקע), בכל בחירת קול, ואחרי הורדה או הסרה של חבילת הקול. קול שהונח בתיקייה בזמן שאוצריא
   פתוחה מופיע אחרי בחירת קול כלשהי בתפריט. התפריט מוגבל ל-20 פריטים, כלומר לעשרה קולות מוקלטים.
   השירות עצמו מכיר את הקול בלי שום הגדרה: `POST /speak` עם `"voice":"<מזהה>"` משתמש בו.
